**🏠 ClearEstate – Real Estate Platform with Transparency Metrics
**
ClearEstate is a full-stack real estate platform designed to bring transparency, trust, and data-driven decision-making into property buying and selling.

Unlike traditional listing platforms, ClearEstate goes beyond just showcasing properties by providing detailed analytics, negotiation tracking, and verified insights to help users make informed choices.

** Key Features
**🔐 Role-Based Authentication
Separate dashboards for Buyers and Sellers

🏡 Property Management
Sellers can list, edit, and manage properties
Buyers can browse, search, filter, and save properties

🤝 Real-Time Negotiation System
Buyers and sellers can exchange offers
Accept / Reject / Counter offers with proper role-based control

Transparent deal tracking
📊 Transparency Metrics
💰 True Price Breakdown
📈 Property History Timeline
🌍 Area Reality Index (ARI)
🧾 Dealer Transparency Score
📩 Buyer Request System
Buyers can send Buy/Rent requests directly to sellers
Sellers can accept or reject requests'

🔔 Notifications System
Real-time updates for offers, requests, and deal status

📉 Analytics Dashboard (Seller)
Insights on listings, negotiations, and properties sold

**🛠 Tech Stack
**Frontend: Next.js, React, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB
Real-Time: Socket.io
APIs: Location & data APIs for ARI and validation
